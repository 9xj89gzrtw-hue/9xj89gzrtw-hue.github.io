# Holler — logo system

Submission for the Holler logo-system brief (Taskmarket `TSK-FXES37VN`).

One recommendation (concept **A**), two complete alternates (**B**, **C**), and every file the
brief lists — vector source, transparent PNGs at 512 / 1024 / 2048, light / dark / busy-video
evidence, usage note and rationale.

Live preview: **https://9xj89gzrtw-hue.github.io/holler-brand/**

---

## 1. The recommendation: concept A — “H tile”

A sheared **H** inside a gradient tile. The two bars are the crowd; the yellow crossbar is the
shout — the one element that breaks the grid, and the only thing still visible when everything
else is scaled down to a favicon.

Why this one:

- **It survives 16 px.** A filled tile with one large cut keeps its silhouette. Thin-line marks
  die in a tab strip. This was the deciding constraint, so the mark was designed at 16 px first
  and only then drawn large.
- **It is one shape, not a drawing.** No gradients inside the letter, no strokes, no effects —
  so it works as one-colour print, embroidery, or a 1-bit favicon without redrawing.
- **It has no red dot and no bare circle.** The reference's record dot read as “camera on” and
  alarmed people who leave tabs open. Nothing here is red, and nothing sits alone in a circle —
  the tile is the container, so the mark never reads as a status light.
- **The shear is a posture, not a style.** 6° forward is enough to feel like it is leaning into
  the room; a full italic would have read as “sports car”, not “arena”.

## 2. Alternates

| | Idea | Strength | Trade-off |
|---|---|---|---|
| **B — Shout bubble** | An open mouth with two teeth inside a speech bubble | Most literal reading of “holler”; gives the brand a face for social | Busiest at 16 px; the mouth detail disappears |
| **C — Echo H** | Gradient monogram with three radiating arcs | Motion for a real-time product; strongest on dark | Arcs thin out on light backgrounds; weakest in one colour |

Both are shipped as *complete* sets (all three colourways + all PNG sizes), so picking a
different direction is a strategy call rather than a redraw.

## 4. Usage note (one page)

**Colour.** Azure `#0A9BFF` → Magenta `#FF2BD6` carries the brand. Yellow `#FFD60A` is an accent
only (the crossbar, one CTA, never a background). Green `#39FF6A` is optional and used only in
concept C's arcs. Ink `#070B14`, Paper `#FFFFFF`.

| Role | Light surface | Dark surface |
|---|---|---|
| Primary | `A-lockup-mono` (ink) | `A-lockup-reversed` (paper) |
| Mark only | `A-mark-mono` | `A-mark-reversed` |
| Feature / hero | `A-lockup-color` | `A-lockup-color` |

**Clear space.** Minimum on all four sides = the height of the crossbar (in the lockup: one stem
width ≈ 0.27 × cap height). No type, no card edge, no other logo enters that box.

**Minimum sizes.** Mark: **16 px** digital / **10 mm** print. Lockup: **160 px** wide digital /
**35 mm** print. Below 160 px, drop the wordmark and use the mark only.

**Do not:** recolour the crossbar to red; place the mono mark on a mid-tone photo; outline,
emboss, or add a drop shadow; re-set the wordmark in a font (it is drawn geometry, not type);
rotate the tile.

**One-colour use.** The mono and reversed files are pre-flattened. Do not convert the colour
file to greyscale — the gradient will band.

## 5. Fonts and third-party assets

**None.** Every mark, letterform and icon is drawn from primitives as SVG paths. There is no font
file, no stock asset, no tracing and no template. Text on the preview page uses the system UI
stack (`-apple-system`, `Helvetica Neue`, `Arial`) and is **not** part of the logo artwork, so it
carries no licence obligation on the logo.

The 6° shear and all geometry are generated by `build.py`, which is included — the system is
reproducible and editable at the source level, not just in Illustrator.
