    Questions

    Where do the stories come from?

    Only from sources you add: public RSS or Atom feeds and public Telegram channel previews at t.me/s/…. Nothing is scraped from private chats.

    Do I need an API key?

    No. The digest is assembled from the feed text itself. If you want a rewritten post, you can add your own Groq or Gemini key in the rewrite dialog; it is stored in this browser and sent only to that provider.

    How is the payment verified?

    The page asks a public Base RPC for the transaction receipt, finds the USDC transfer to our address and checks the amount. If it matches, Pro is stored in localStorage. Nothing is sent to a server of ours because there is no server.

    What happens if I clear my browser data?

    The Pro flag is local, so clearing site data removes it. Keep the transaction hash: paste it again in the same dialog and it re-unlocks on that device.
